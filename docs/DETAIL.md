# 对话完成提醒

一轮对话真正跑完时叫你回来：默认在 DSH 页面右下角弹一条提示并响一声，可选再叠加 Windows 托盘气泡。

## 页面内提醒（默认开启，无需配置）

- 任何会话从「运行中」变成「空闲」时触发，不只当前打开的那个。
- 右下角出现一张卡片：「一轮对话完成 / 会话名 / 点击回到这个会话」，8 秒后自动消失。
- **点卡片直接跳到那个会话**；卡片右上角的 × 只关掉提示，不跳转。
- 同一时间最多叠三张，后来的把最早的挤掉。
- 同时播放两音提示音（Web Audio）。浏览器在你首次交互前可能拦截音频，点过页面后恢复正常。
- 子代理会话不触发。

## 什么时候不响

- 这一轮用时少于 `minDurationMs`（默认 3 秒）。
- 两次提醒间隔小于 `minGapMs`（默认 2.5 秒）时，后来的会被丢弃，防止多会话同时结束时连环响。
- 子代理会话结束。
- 与具体结束原因无关：页面内提醒只看「运行 → 空闲」，出错、手动停止都会提示。这一点比 Windows 气泡那条通道宽松。

## Windows 托盘气泡（可选，默认关闭）

Host 端还会在 `turn/end` 时拉起一次性 PowerShell 弹气泡、播系统提示音。**在这台机器上实测：脚本正常执行、无异常，但系统不显示气泡、也听不到声音**，所以默认关掉（`balloon: false`、`sound: false`）。你的机器上如果系统通知正常，把这两项改回 `true` 即可。

## 配置

改 `cordis.patch.yml` 里本插件的 `config`；没写的键用默认值。

| 键 | 默认 | 作用 |
|---|---|---|
| `minDurationMs` | `3000` | 短于此时长的一轮不提醒（只影响 Windows 通道；页面内提醒不看时长） |
| `minGapMs` | `2500` | Windows 通道两次提醒的最小间隔 |
| `balloon` | `false` | Windows 托盘气泡开关 |
| `sound` | `false` | Windows 系统提示音开关 |
| `soundFile` | `''` | 自定义 wav 绝对路径；空则用 Windows 默认通知音 |
| `notifyOnError` | `true` | Windows 通道：出错的一轮是否提醒 |
| `notifyOnAbort` | `false` | Windows 通道：手动中断是否提醒 |
| `titlePrefix` | `'DSH'` | 气泡标题前缀 |
| `language` | `'zh'` | Windows 通道文案语言 |

Windows 通道的 `blocked`、`max-tokens`（输出被截断）、`interrupted` 三种结束原因一律不提醒。

## 已知限制

- 页面内提醒只在 DSH 页面开着时可见；页面关掉就收不到（这时才需要 Windows 通道）。
- Windows 气泡是原生样式，点它只能把焦点还给 DSH，跳不到具体会话。
- Windows 通道连续三次失败（进程起不来、脚本非零退出）后自动停用，只在日志里说明。
- 页面内提示音依赖浏览器音频输出；没有音频设备时只有卡片、没有声音。
